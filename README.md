# Lab de Tráfego Pago — Smart Empreender

Formulário público dos participantes da Conferência Smart Empreender, Igreja da Árvore.

https://ecodigital-dev.github.io/smart-empreender-lab/

Campos: nome, empresa, e-mail e confirmação de e-mail. O envio é validado pelo servidor e só confirmado após gravação. Este repositório contém somente a página; inscrições ficam fora do repositório público.

A lista CSV é sincronizada em `ecodigital-dev/smart-empreender-participantes`, repositório privado do organizador, a cada hora ou por execução manual do workflow. O acesso ao curso é liberado posteriormente pela organização.

Página estática sem dependências de compilação. Hospedagem pelo GitHub Pages, branch `main`, raiz. Acesso administrativo por GitHub CLI autenticado no chaveiro, sem credenciais versionadas.
